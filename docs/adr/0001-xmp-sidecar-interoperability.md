# Dual-Convention XMP Sidecar Discovery and Interoperable Rating Schema

Pickture must exchange non-destructive metadata with Capture One, Adobe Lightroom, and Adobe Bridge without ever modifying original image or video files. Because Lightroom/Bridge default to `<basename>.xmp` (shared across RAW+JPG pairs) while Capture One and Darktable can produce `<filename>.<ext>.xmp`, Pickture reads both conventions (preferring `<basename>.xmp` when both exist) and writes to `<basename>.xmp` by default while also updating `<filename>.<ext>.xmp` if one already exists on disk. For metadata encoding, Pickture stores `PickFlag` in `crs:Pick` (`1`, `0`, `-1`) and `xmpDM:pick`, `StarRating` (`0`–`5`) in `xmp:Rating` (treating an incoming `xmp:Rating="-1"` without `crs:Pick` as `Rejected` + `0` stars on read), and `ColorLabel` in `xmp:Label`, preserving all unrelated XML namespaces and nodes intact during round-trip writes.
