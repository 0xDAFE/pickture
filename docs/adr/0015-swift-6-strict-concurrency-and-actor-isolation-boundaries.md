# Swift 6 Strict Concurrency Architecture and Isolation Boundaries

To achieve compile-time data-race safety across macOS, iOS, and iPadOS while preserving 120 FPS culling performance, Pickture adopts the Swift 6 language mode (`SWIFT_VERSION = 6.0`) with Approachable Concurrency. Because the Xcode application target enables `SWIFT_DEFAULT_ACTOR_ISOLATION = MainActor` to simplify SwiftUI view composition and `@Observable CullingSession` bindings, all domain layers responsible for disk I/O, SQLite indexing, and in-memory caches must be explicitly isolated from `@MainActor`. `SQLiteMediaCacheIndex`, `DirectoryListingCache`, `DecodedImageCache`, `StorageVolumeProfile`, `SidecarCodec`, `XMPDocumentTree`, and `RecordCache` are designated as `nonisolated` (or isolated to dedicated background actors such as `MediaCache` and `ThumbnailQueueActor`), ensuring that SQLite WAL queries, directory scans over remote SMB shares, and XML sidecar serialization never execute on the Main RunLoop (reaffirming ADR-0012 and ADR-0013).

To guarantee absolute database invariants without forcing asynchronous lifecycle cascades into SwiftUI state models, `actor MetadataSyncStore` implements synchronous, invariant-enforcing initialization. Database file opening, WAL journal configuration (`PRAGMA journal_mode = WAL`), synchronous disk pragmas, schema table creation, and in-memory record cache hydration are executed during `init` via pure nonisolated static helpers directly on the SQLite `OpaquePointer` before assigning `self.db`. This eliminates the need for an artificial `async init` or post-init bootstrap phase, ensuring an actor instance can never exist in an un-migrated or un-schematized state while allowing `@Observable CullingSession` to remain synchronously instantiable in `@State`.

To eliminate compiler escape hatches and unsafe workarounds, cross-boundary tasks adhere strictly to Value Transfer semantics. In `PreviewLoader`, non-Sendable Core Foundation reference handles (`CGImageSource`) are never passed across `@Sendable` concurrency boundaries into actor-isolated permit blocks. Instead, the immutable, natively `Sendable` `URL` value is transferred across the boundary, with the temporary `CGImageSource` instantiated and consumed strictly within the isolated permit scope. This guarantees 100% compile-time concurrency verification without relying on `@preconcurrency import ImageIO` or `@unchecked Sendable` wrappers.
