# Progressive Metadata Rendering Without Synchronous View I/O

View rendering passes and computed property evaluation (such as aspect ratio calculation in grid cells or camera and lens filter menus in `FilterCriteriaBarView`) must never perform synchronous file reads, SQLite queries, or image decoding on `@MainActor`, especially when operating over high-latency network shares (SMB/NAS). Pickture enforces strict in-memory resolution for all view layout and filtering metrics: missing or unindexed metadata immediately yields deterministic fallback values (e.g. fallback aspect ratios or sorting undated items to the tail).

As background preloading pipelines (EXIF header extraction, thumbnail decoding, and metadata hydration) asynchronously populate attributes, updates are batched and throttled to progressively re-sort sequences, populate facet menus, and refine cell geometry without blocking the main runloop or disrupting the user's active selection. Per-file thumbnail aspect ratios are persisted alongside cached thumbnails in the local SQLite `MediaCache` index and warmed into memory on workspace open, eliminating synchronous disk or database lookups during scrolling.
