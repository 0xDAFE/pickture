# Adaptive Split-View Navigation and Compact Workspace Hierarchy

Because Pickture runs across macOS, iPadOS, and iOS, top-level navigation must gracefully transition between multi-column desktop/tablet layouts and compact single-stack iPhone screens (including iPad Slide Over) without duplicating view code or maintaining disjoint navigation trees. Rather than replacing `NavigationSplitView` with a platform-conditional `NavigationStack` or modal sheet, Pickture uses a single `NavigationSplitView` driven by an explicit `@State private var preferredCompactColumn: NavigationSplitViewColumn`. 

On compact screens, the app launches anchored to the sidebar (`.sidebar`), where the Settings gear button is hosted in the top-trailing toolbar for immediate pre-session accessibility. When a folder is successfully opened or reopened, the hierarchy automatically programmatically advances `preferredCompactColumn` to `.detail`, presenting the Workspace (Grid or Filmstrip). Failed folder loads remain on the sidebar with an inline error banner. When returning to the sidebar via native back navigation, an "Active Workspace" section displays the loaded directory and item count with quick-action links to "Return to Grid" and "Close Folder". 

To prevent navigation bar clipping on compact widths, workspace controls adapt based on `@Environment(\.horizontalSizeClass)`: compact widths display primary actions (`Filter`, `ViewMode`, `SyncState` badge) with secondary session toggles (`BorderTapNavigation`, `SwipeMode`, `PreviewSource`, `AutoAdvance`, `DockPosition`, `Settings`) grouped into a "More" (`…`) menu, while regular widths preserve direct one-click toolbar buttons.
